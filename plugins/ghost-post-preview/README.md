# Ghost Post Preview

> Predict engagement before you publish.

**Category:** Social Media · **Tier:** Flagship

## Overview

Ghost Post Preview runs a draft post against a synthetic audience model to predict engagement before it goes live, so creators and businesses focus effort and ad spend on high-converting content.

## Target audience

Creators, social media managers, and businesses running paid or organic content.

**The pain it solves:** Marketing spend and effort wasted on content that underperforms — discovered only after publishing.

## Skill required to leverage it

Audience definition — users must describe their real audience segments accurately, since the synthetic model is calibrated from those inputs.

## Monetization

Directly tied to revenue. Subscription tiers by prediction volume; agency tier with multi-brand audience models.
