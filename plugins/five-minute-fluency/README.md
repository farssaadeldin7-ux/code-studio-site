# 5-Minute Fluency

> Personalized cheat sheets generated from your own gameplay.

**Category:** Gaming · **Tier:** Flagship

## Overview

5-Minute Fluency watches gameplay and generates a personalized cheat sheet — the on-demand coach for players who want to improve rapidly without hours of research.

## Target audience

Competitive gamers and ranked-ladder players.

**The pain it solves:** Improvement requires hours of guide-reading and VOD review that most players never do.

## Skill required to leverage it

Session tagging — users should label the game, mode, and goal of each session so the generated sheet targets the right meta.

## Monetization

Most scalable option in the portfolio. Subscription 'on-demand coach' for competitive gamers; per-game content packs.

## Roadmap

- [ ] Gameplay capture ingestion (clips, match logs)
- [ ] One-page cheat sheet generator
- [ ] Progress tracking across sessions
