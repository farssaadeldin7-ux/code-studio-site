How activation works

  1. 1

    Install the plugin

    From Open VSX, the plugin marketplace, or npm — the plugin itself is a free install.

  2. 2

    Buy a plan

    Checkout takes a minute; the licence key is shown immediately after payment.

  3. 3

    Paste the key

    Tell the plugin to activate — it stores the key on your machine and every paid tool unlocks.
