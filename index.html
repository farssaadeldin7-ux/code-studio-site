How it works

  1. 1

    Install & add your key

    Grab Code Studio for your platform and paste your Anthropic API key. Get one at console.anthropic.com.

  2. 2

    Select or paste code

    Highlight a snippet, open a file, or paste into the box — any language.

  3. 3

    Refactor — and read the why

    Claude streams back a one-line "why refactor" summary followed by concrete suggestions, right where you're working. (Prefer docs? Hit Document.)

Code Studio has no server of its own. Requests go straight from your device to the Anthropic API using your key — nothing is stored or proxied.
