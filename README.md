# Code Studio — website

Marketing/landing site for **Code Studio**, the AI **Refactor Assistant** powered by Claude — concrete refactoring suggestions with a built-in 1–2 sentence explanation of why.

Static HTML/CSS, hosted on GitHub Pages. To work on it locally just open `index.html` in a browser (no build step).
